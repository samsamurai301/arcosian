# Research behind Arcosian

The October 2026 research that shaped the design: what the market and the open-source ecosystem offered for AI-assisted mobile game development, which engines, generation models and services to build on, and how a Claude Code plugin should be structured. It was written before the project had its name, so it describes "the plugin" in general terms; projects such as Claude-Code-Game-Studios that it mentions are other people's work.
